# kosen-mcc

国立高等専門学校機構「モデルコアカリキュラム」（令和 5 年版）の内容を、AI エージェントが参照しやすい形式に転記したリポジトリです。到達目標、他の基準との対応、考え方を説明した散文までを、ID とページ付きで引けるようにしています。

| 項目 | 値 |
| --- | --- |
| 原本の名称 | モデルコアカリキュラム |
| 発行者 | 独立行政法人 国立高等専門学校機構 |
| 発行日 | 令和 5（2023）年 4 月 28 日 |
| URL | https://www.kosen-k.go.jp/wp/wp-content/uploads/2023/12/2c383e29-7e20-4b20-af19-ca3737450665.pdf |

## 使い方

AI エージェントは `AGENTS.md`（Claude Code は `CLAUDE.md`）を読んでください。引き方はスキル `mcc-lookup` にあります。

スキルを自分のプロジェクトに取り込むコマンド:

```bash
npx rulesync fetch atsuki-seo/kosen-mcc --skills mcc-lookup
```

人が読む場合は `build/by-field/` の分野ごとの Markdown を開いてください。

## 構成

| パス | 役割 |
| --- | --- |
| `data/` | 正本。到達目標などのノード、関係、誤記の記録、画像照合の記録 |
| `text/` | 正本（散文）。節ごとの Markdown、図の画像と書き起こし |
| `build/` | 正本から生成した、検索・閲覧用のファイル |
| `extensions/` | 原本にない付加情報（正本とは別の層） |
| `skills/` | 外部へ配布するスキル `mcc-lookup` |
| `schema/`、`config/`、`tools/` | スキーマ、抽出の設定、抽出・検査・生成のスクリプト |
| `source/` | 原本の出典情報と取得スクリプト（原本の PDF は含まない） |
| `docs/` | 設計（`design.md`）と開発の手引き（`development.md`） |

## 正確さについて

- 権威は原本です。このリポジトリの内容と原本が食い違う場合は、原本が正しいものとして扱ってください
- 転記はすべてスクリプトで行い、原文を言い換えていません。原本の表記ゆれや誤記も直さず、別に記録しています
- 各レコードは確認の状態を持ちます。`machine` は原文が原本の該当ページに含まれることを機械で確かめた状態、`image` はページの画像と突き合わせた状態（AI エージェントによる照合）、`human` は人が原本と見比べた状態です
- 誤りを見つけたら、GitHub の Issue で知らせてください
